## Featured open-source project

### 🧰 [Developer Playground](https://github.com/muhammadsaadjalil/developer-playground)

Small Python command-line utilities designed for everyday development tasks, with no third-party runtime dependencies.

| Utility | Purpose |
| --- | --- |
| Text Statistics | Count words, lines, characters, and optional UTF-8 bytes |
| JSON Formatter & Validator | Format, validate, minify, and sort JSON keys |
| CSV Analyzer | Inspect rows, columns, and missing values |
| SHA-256 Checksum | Calculate or verify file hashes |
